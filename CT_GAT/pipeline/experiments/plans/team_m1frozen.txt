# network, averages the block vectors and classifies) and then `train_b --arm sig500v3-m1frozen`, which encodes each block once with
# that Model 1's best_auc.pt and trains only Dorothy's GAT on the block vectors; it exits unless the Model 1 is of the same fold,

# reads by default, and the arm compares the two api_vocab.json). Seeds 0 1 2, folds 0-4 (15 pairs per group, seed by seed, each
# Model 1 before its arm).

#   same with --arch-balance (the `-ab` twins: cell weights in both the Model 1 loss and the arm's, 2 groups, 30 runs).
# 6 groups, 90 runs. `gates team` and `gates team_mendeley_all` pair `emb -> m1frozen` (what the frozen Model 1's block vectors
