#   b_sig500_mendeley_all, b_sig250_mendeley_all, b_callwalk500_mendeley_all, b_callwalk250_mendeley_all, b_sigwhole_mendeley_all

# architecture cell weighted equally) of `sig500v3-feat|emb|e2e` and of the two Model 1 groups follow the signal-500 block: 5 groups,
# 75 runs. The other twins are added the same way, one line pattern per group.
# The queue takes the builds in this order, so a build that is still being made comes last; a line whose build is missing or
# unfinished fails on its first run and is started again once the build is done. On the whole Mendeley dataset the architecture is a

# `team_mendeley_all` by its per-architecture recalls and cell-balanced columns, not by its AUC alone.
#     python -m experiments.queue --plan experiments/plans/team_mendeley_all.txt --budget-min 1800
